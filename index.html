02Retrieved Kali's local IP via ifconfig — provided to SET so POST requests route back to the attacking machine
03Entered https://www.facebook.com as the URL to clone — SET replicated the login page and began listening for POST requests
04Navigated to the cloned site in Firefox via local IP — entered a test username and password on the fake login page
05Returned to SET terminal — located plaintext username and password values in the captured POST request output
🎯
Key Finding — Successfully captured credentials submitted to a cloned Facebook login page. POST requests sent credentials in plaintext directly to the attacker's machine — demonstrating the mechanics of phishing, credential harvesting, and why HTTPS and domain verification are critical.

Dictionary Attack with Hydra
Hydra · Kali Linux · Password Cracking · HTTP POST · rockyou.txt
✓ COMPLETED

01Opened target in Firefox — used DevTools Network tab to capture the POST request and copy tfUName and tfUPass parameters
